# ماژول برنامه‌ریزی موارد — ۱.۹.۹۸

مسیر UI: فهرست کشویی ماژول‌ها → برنامه‌ریزی موارد → تنظیمات و دریافت از CRM.

فهرست Viewهای مورد/یادداشت از CRM خوانده می‌شود. انتخاب تا ذخیره صریح کاربر اثر ندارد. نام، شناسه GUID و نوع userqueries/savedqueries در `planning_crm_settings` SQLite نگهداری می‌شود. خواندن فهرست و ورود مجدد هیچ انتخاب خودکاری انجام نمی‌دهد. در صورت حذف View یا نبود دسترسی، خطا نمایش داده می‌شود و View دیگری انتخاب نمی‌شود. اعتبارنامه فرم فقط برای درخواست جاری است و ذخیره نمی‌شود؛ هویت Windows پیش‌فرض است.

## همگام‌سازی

`planning.PlanningApiMixin` قرارداد مستقل Bridge است: get_planning_settings، get_planning_views، save_planning_settings، sync_planning_view، get_planning_sync_status.

Snapshot از جدول موجود crm_snapshots با source=`planning:`+hash(endpoint/organization/API/view-ID/kind) استفاده می‌کند. Cursor و داده هر View مستقل‌اند. Snapshot پیش‌فرض ارزیابی اکنون فقط source=dynamics365 را می‌خواند؛ هیچ دریافت برنامه‌ریزی Dataset یا Result ارزیابی را تغییر نمی‌دهد.

اولین دریافت همه رکوردهای View را می‌گیرد. دفعات بعد `modifiedon` از زمان UTC شروع آخرین دریافت موفق خوانده می‌شود؛ یک ثانیه هم‌پوشانی برای دقت زمانی دارد و نتیجه با شناسه Note/Task و مقایسه محتوای رکورد ادغام می‌شود. پس همان رکورد دوباره اضافه یا دوباره تغییرکرده شمرده نمی‌شود. فیلترهای View حفظ می‌شوند. روی View مورد، تغییر Note/Task مرتبط با همان View نیز با شرط modifiedon خوانده می‌شود. فهرست View با GUID مستقیم شناسایی می‌شود؛ تشابه نام باعث انتخاب اشتباه نیست.

Cursor تنها پس از دریافت موفق همه صفحات و ذخیره Snapshot جلو می‌رود. پاسخ ناقص، صفحه تکراری یا عبور از حد ایمنی خطاست. حذف رکورد یا خروج از شرط View در دریافت افزایشی بررسی نمی‌شود؛ دریافت کامل دوره‌ای خودکار هم برای این ماژول وجود ندارد. اگر تعریف خود View در CRM عوض شود، بازتنظیم داده نیازمند سیاست جداگانه است.

UI مرحله جاری، زمان سپری‌شده، شمار جدید/تغییرکرده و آخرین دریافت شمسی را نشان می‌دهد. تعداد کل نامعلوم به درصد قطعی تبدیل نمی‌شود. ادمین می‌تواند فهرست/انتخاب را تغییر دهد؛ تحلیلگر دریافت و مشاهده دارد؛ مشاهده‌گر فقط مشاهده تنظیمات/وضعیت دارد. مجوز Backend مرجع نهایی است.

تست‌ها: ماندگاری انتخاب، جداسازی منابع Snapshot، ادغام بدون تکرار، حفظ داده قبلی، تغییر منبع با View جدید، خطای شبکه بدون پیش‌روی Cursor و عدم دست‌کاری ارزیابی. EXE قبلی خودکار تغییر نمی‌کند؛ این مرحله سورس است.
