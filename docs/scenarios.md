# سناریوهای واقعی

## تحلیل یک Dataset

کاربر دو فایل Notes و Tasks را انتخاب می‌کند. سیستم ستون‌ها را تشخیص می‌دهد،
رکوردها را Normalize می‌کند، Taskها را به Case وصل می‌کند و خلاصه Validation
را نشان می‌دهد. کاربر Mode و تنظیمات را انتخاب و تحلیل را اجرا می‌کند؛ نتیجه
در Dashboard و گزارش‌ها قابل مشاهده و Export است.

## تحلیل کلی یک Case

کاربر در جدول Cases یک مورد را باز می‌کند. سیستم Timeline و Breakdown فعلی را
نمایش می‌دهد. اگر AI فعال باشد، کاربر «بررسی این کیس با AI» را می‌زند. Worker
پاسخ Provider را اعتبارسنجی می‌کند و پس از موفقیت همان Breakdown با Evidence
جدید به‌روزرسانی می‌شود.

## انتقال تنظیمات

کاربر کل پوشه `MyBarid-AI-Portable` را کپی می‌کند. در مقصد معیارها، گروه‌ها و
تنظیمات Provider از فایل‌های کنار EXE خوانده می‌شوند. به‌دلیل DPAPI، ممکن است
کلید API نیاز به ورود مجدد داشته باشد؛ این رفتار امنیتی عمدی است.

## اضافه‌کردن Rule

Developer تابع Rule را در `analysis/rules.py` اضافه می‌کند، آن را در
`RULE_FUNCTIONS` ثبت می‌کند، Criterion و Guide را در `config` تکمیل می‌کند و
تست N/A/Score می‌نویسد. سپس API، Export و UI بدون تغییر اساسی از Criterion
جدید استفاده می‌کنند.
